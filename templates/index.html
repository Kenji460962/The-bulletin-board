talk-ch の使い方ガイド

トークちゃんねるへようこそ！初めての方でも安心して楽しめる基本的な使い方をご案内します。

1. スレッドを閲覧・書き込む

  • スレッドを探す: 「スレ一覧」タブから興味のある話題を選ぶか、上部の検索バーやカテゴリフィルターで検索できます。
  • レス（返信）を書く: スレッド内の投稿フォームから、名前（省略可）と本文を入力して投稿できます。
  • アンカー機能: 本文中に >>1 や >>5 のように入力すると、過去の書き込みにリンクできます。
  • 画像つきの投稿: 投稿フォームの「画像」から写真を添付できます。選んだ画像は横にプレビューが出て、「✕ 取り消し」で選び直せます。大きな画像は自動で軽く変換されます。
  • 投稿のルール: 本文は500文字までで、連続投稿は3秒あけてください。
  • 閲覧モード / リアルタイムモード: スレ画面右上で「スレ閲覧」と「リアルタイム」を切り替えられます。リアルタイムでは新しいレスがすぐ表示されます。

2. 新しいスレッド（板）を立てる

  • 「スレ一覧」タブの上部にある「新しい板（スレッド）を立てる」フォームから作成します。
  • 話題に合った「カテゴリ」を選択し、50文字以内でタイトルを入力して送信してください。
  • 送信すると確認画面が開きます。タイトル・カテゴリ・タグを確かめて「スレッドを作成する」を押すと立ちます。
  • スレ立ては続けてできません。5分に1回までです（VPN・プロキシ経由は15分）。

3. 便利な機能

  • ダークモード切り替え: 右上の「ダーク表示 / ライト表示」ボタンで画面デザインを切り替えられます。
  • スレ番号ジャンプ: スレ一覧にある「スレ番号でジャンプ」にID番号を入力すると、目的のスレに一発で移動できます。
  • ミニゲーム: サイドバーの「ゲーム」タブから、ブラウザで遊べるオセロ・チェス・将棋を楽しめます。戦績とレーティングはプロフィールに表示され、ゲームタブの「ランキングを見る」で順位も確認できます。
  • オンライン人数と在室ユーザー: スレ画面の上部に「オンライン人数: ◯人」が出て、人の出入りに合わせてリアルタイムで変わります。押すと、いまそのスレにいる人の名前とIDが一覧で出て、名前を押すとその人のプロフィールに移動できます（ログインしていない人は「ゲスト」としてまとめて表示されます）。
  • 過去スレ: サイドバーの「過去スレ」から、過去のスレッドを見られます。

4. アカウント・プロフィール・フォロー

  • 会員登録・ログイン: 登録すると、プロフィール・フォロー・メッセージ・ポイント・取引所が使えるようになります。
  • プロフィール: アイコンと自己紹介を設定できます。自分のプロフィールの「プロフィールを編集」から変更してください。作成したスレッド数・総レス数、ゲームの戦績もここに表示されます。
  • フォロー: 気になる人のプロフィールで「フォローする」を押します。フォロワー数・フォロー中の数を押すと一覧が見られます。お互いにフォローし合うと「相互フォロー」になります。
  • ブロック: プロフィールの「ブロック」を押すと、互いのフォローが外れ、メッセージのやり取りもできなくなります。同じ場所から解除もできます。
  • 通報: プロフィールの「通報」から、理由を選んで運営に知らせられます。

5. メッセージ（DM）

  • 送れる相手: 相互フォローの相手だけです。相互フォローになると、プロフィールに「DMを送る」ボタンが出ます。
  • 入口: サイドバーの「メッセージ」から会話の一覧に入れます。未読があると、メッセージのアイコンに件数バッジが付きます。
  • リアルタイム: メッセージは相手の画面にすぐ届きます。1通は1000文字までです。
  • 写真を送る: 入力欄の左の📷から写真を選ぶと、プレビューが出ます（「取り消す」で外せます）。8MBまで、jpg / png / webp / gif に対応しています。送った写真は、その会話の2人だけが見られます。

6. ポイントの貯め方・使い方

  • ログインボーナス: ログインして掲示板のトップかスレを開くと、1日1回、10ポイントがもらえます（日付は日本時間で切り替わります）。連続ログインでさらに追加があります：7日目 +10、14日目 +20、30日目 +50。1日でも空くと連続日数は1に戻ります。
  • スレ主ボーナス: 自分が立てたスレに、他の人がレスするたびに1ポイントもらえます。自分のレスには付きません。
  • ポイントを貯める（広告）: 「オファーウォール」のページで、提携の広告タスクをこなすとポイントがもらえます。
  • 残高と履歴: 自分のプロフィールの「ポイント」欄から、残高と履歴のページを開けます。
  • ポイントを送る: 相手のプロフィールの「ポイントを送る」から送金できます。1回につき1〜100,000ポイントで、確認画面が出ます。送金の取り消しはできません。送る相手をよく確かめてください。
  • 使い道: サイドバーの「取引所」で、壁紙やフォントなどと交換できます。

7. 取引所（ポイントで売買）

  • 公式商品: 運営（Talk-ch公式）が、フォント・壁紙などを出品しています。購入代金は運営に入ります。
  • ユーザーの出品: 会員は自作の壁紙・Webプロキシ・その他を出品できます（フォントの出品は公式のみです）。「取引所」から出品フォームを開き、タイトル・説明・価格・画像を入力します。売れると、代金が出品者のポイントになります。
  • 購入とインベントリ: 商品ページで「購入する」を押すと、ポイントが引かれてインベントリに入ります。同じ商品を2回買うことはできません。自分の出品は買えません。
  • 壁紙・フォントを使う: 壁紙は「適用する」を押すとスレ画面の背景が変わります（自分の画面だけで、他の人の表示は変わりません）。フォントを適用すると、自分のレスがその書体で表示されます。「適用を解除する」でもとに戻せます。
  • Webプロキシ: 購入前はURLが見えません。購入した人にだけURLが表示されます。
  • 評価とショップ: ユーザーが出品した商品は、購入した人が★1〜5とコメントで評価できます（公式商品は評価できません）。出品者の名前を押すと、その人のショップ（出品一覧）に移動できます。プロフィールにも「ショップを見る」があります。
  • 18歳以上のコンテンツ: 18歳以上向けの商品は、一覧では画像と説明が伏せられます。商品ページの「表示する」を押して、確認で18歳以上と答えると表示されます。出品者は、該当する商品に必ずチェックを付けてください。運営が18歳以上と判断した商品は、運営が設定します。
  • 通報: 規約に反する商品は、商品ページの「🚩通報する」から運営に知らせられます。

8. 謎機能

  • サーバー状況: サーバーのCPU,メモリ、ネットワークの稼働率のグラフです。見れるから何があるとかはありません。シンプル管理人の趣味です。疲れたときにぼーっと見るのもいいかもね。

9. 利用ルールとマナー

みんなが快適に利用できるよう、以下のマナーをお守りください。

  • 誹謗中傷、差別的発言、過度な荒らし行為は禁止されています。
  • 個人情報（本名・電話番号・住所など）は書き込まないでください。
  • 取引所で18歳以上向けの商品を出品するときは、必ず「18歳以上のコンテンツ」にチェックを付けてください。
  • スレッド・レス・ユーザー・商品には、それぞれの画面の「通報」ボタンから通報できます。個別に連絡したい場合は、下の窓口をご利用ください。
  • 違反・不適切な投稿を見つけた場合は、サイドバーの「通報窓口・お問い合わせ」よりご連絡ください。
